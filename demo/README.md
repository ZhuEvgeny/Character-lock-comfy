# Demo

Add `demo.mp4` (≤ 2 minutes) before submitting:

1. Open ComfyUI → Load `workflows/character_lock_v1.json`
2. Set Load Image to `examples/input_ref.png` (or your ref)
3. Queue Prompt; change seed for a second direction
4. Screen-record: load → generate → show two locked outputs

Judges care about the workflow working, not video polish.
